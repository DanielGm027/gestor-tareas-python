# Gestor de tareas en Python

Autor: Carlos Daniel Gómez González.

Proyecto de la Actividad 1 para desarrollar una aplicación de consola que
permita agregar, listar y completar tareas. Usaré Singleton para compartir
la configuración, unittest para las pruebas y JSON para guardar los datos.

## Ejecución

Requiere Python 3.10 o posterior. No necesita paquetes externos.

```bash
python main.py
```
